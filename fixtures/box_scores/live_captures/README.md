# Live captures

Attributed snapshots pulled from public ESPN JSON during beta development.

Each file includes `source_url` and `fetched_at_utc`. Companion `*.coaching.json`
files store play-by-play-derived substitutions, foul tallies, hot/cold windows,
simple role grades, and rotation frequency baselines.

**Rights:** suitable for internal testing with provenance. Commercial redistribution
/ production hosting requires an explicit rights review before deploy.
